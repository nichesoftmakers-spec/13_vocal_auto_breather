# 【Windows専用】VocalAutoBreather GUI ｜ ボーカルブレス・無音区間の自動フェード・息継ぎ音最適化機

> **「歌ってみたの録音トラック、フレーズの合間のブレス（息継ぎ）や暗騒音を手作業で1箇所ずつ切るのが面倒すぎる…」**  
> **「ノイズゲートをかけると歌い出しのサ行や語尾の余韻がブツッと切れてしまう…」**

『VocalAutoBreather GUI』は、「歌ってみた」のMIX師・ボーカリスト・音声配信者のために開発された、**息継ぎ（ブレス）やフレーズ間の暗騒音を自動検出し、滑らかなS字フェードや自然な音量減衰（ダッキング）を一括適用するWindows専用ポータブルGUIツール**です。

面倒なインストール作業は一切不要。解凍してダブルクリックするだけですぐに使えます。

---

## 💡 このツールで解決できるお悩み

- **ちまちましたフェード書き作業からの解放**: 何十箇所もあるフレーズ間のブレスやノイズを、DAW上で1つずつ切ってフェードイン・フェードアウトする膨大な手作業（30分〜1時間）をワンクリックで一瞬で終わらせます。
- **息継ぎ音を完全に消さず、自然に音量だけ下げる**: ブレスを不自然にバッサリ消去するのではなく、歌のグルーヴ・息遣いを残したまま「-6dB」「-9dB」「-12dB」など指定した音量だけ自然にダッキングできます。
- **歌い出しの子音・消え際のビブラートを100%守る**: 「子音・アタック保護（Attack Guard）」と「消え際保護（Release Hold）」により、歌い出しの破裂音や囁き声の頭切れ、語尾のロングトーンの途切れが絶対に発生しません。
- **ブレス単体トラックの同時書き出し（Stem Split）**: 「メインのクリーンボーカル」と「息継ぎ音だけを抽出した別トラック」を同時出力。DAW上でブレスだけに別のリバーブやEQをかけたいプロのこだわりにも応えます。

## 🛠️ 主な機能・特徴

1. **用途別ワンクリックプリセット完備**
   - **ポップス・歌ってみた標準**: ブレス自然減衰 -9dB / S字フェード（25ms/50ms）
   - **バラード・エモーショナル**: ブレス控えめ減衰 -6dB / 滑らか長尺フェード（35ms/80ms、ホールド150ms）
   - **ロック・ラップ**: 暗騒音完全カット（Mute） / 高速フェード（15ms/30ms）
   - **ナレーション・朗読**: ブレスしっかり低減 -15dB
   - **カスタム**: 各パラメータを1ms・1dB単位で自由設定
2. **Raised Cosine（コサイン二乗/S字カーブ）フェード**
   - 直線フェードと異なり、波形の立ち上がりと減衰が極めて自然で、耳障りなプチッというクリップノイズが一切出ません。
3. **プロ仕様・完全コントロール設計**
   - すべての機能（Attack Guard、Release Hold、Stem Split、フェード形状、ノイズ自動測定）を「詳細設定」から個別に完全ON/OFF・数値調整可能。
4. **案件納品用 証明CSVレポート自動出力**
   - 検出フレーズ数、ブレス区間比率、適用減衰dB、保護状態を一覧化したCSVレポートをZIPに自動同梱。
5. **完全ローカル＆文字化け永久防止設計**
   - 外部通信は一切行わず、元ファイルを上書きしない非破壊設計。ZIP内ファイル名は100% ASCII準拠でWindows展開時も文字化けしません。

## 🚀 使い方（3ステップで完了）

1. **プリセットまたは減衰量の選択**
   - 「1. 歌唱ジャンル・用途プリセット」からお好みのスタイル（例: ポップス・歌ってみた標準）を選択します。
2. **音声ファイルの選択**
   - 「2. ボーカル音声ファイルの選択」に対象のWAV/MP3/FLAC音声をドラッグ＆ドロップします。
   - ※迷ったときは「📊 環境ノイズ自動測定」ボタンを押すと、お使いのマイク環境に最適な閾値を自動判定します。
3. **実行とダウンロード**
   - 「🚀 自動フェード＆ブレス最適化を実行」をクリックします。
   - 処理完了後、プレビュー試聴で確認し、「📦 最適化済みWAV ＆ 納品レポートを一括ダウンロード（ZIP）」をクリックして保存します。
